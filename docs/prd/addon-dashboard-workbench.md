## 二、行业中性判断

- **主材销售共性(迁)**:装修单维度的主材销售阶段追踪(报价→签约→施工→安装决算→完结)/月度目标(金额+户数)逐级拆分/缺口与时间进度/异常预警(逾期跟进/目标落后)——「跟单」是主材销售的行业通用动作;
- **方林嫌疑(不迁)**:「作战/战报」话术(行业中性化=「工作台/跟单」)/组织硬编码(设计公司·分区·部门死名)→营造=org 树+S2 数据范围/品类节点配置耦合品类表(销售单明细自由文本,V1 不建品类节点)/「云客工作机/排班/渠道推广」等周边模块(与本族无关);
- 截图「阶段判定:签约/开工/油工结束/安装+决算 里程碑(演示数据)」——里程碑口径各企业不同,**营造落为组织级可配**(V1 常量,同 construction 节点模板先例,V2 可配)。

## 三、营造收敛设计

### 1. 五阶段判定(零新表,状态推导,判定表随 PRD 定稿)

| 阶段 | 判定(行业中性口径,V1 常量) |
|---|---|
| ① 报价跟进 | 存在报价单(attstatus<3)且装修单未签约(status<3) |
| ② 签约待开工 | 装修单签约(3/4)且工程线未开工(project_status=0) |
| ③ 硬装施工 | project_status=1(开工)且未完工 |
| ④ 安装决算 | project_status=2(完工)且名下销售单未全完结 |
| ⑤ 完结 | 全部销售单完结(sales status=5)或装修单完工决算(8) |

- 停留天数=进入当前阶段至今(sales_track/decoration 时间戳推导;无时间戳的判定点以单据 created_at 近似,V1 诚实边界);
- 判定为只读推导函数(QuotationApi/DecorationApi/SalesApi 既有契约拼装),**不落库不建表**——口径改=改函数,零迁移。

### 2. 主材业绩线(target V1.4)

- target_plan/target_stage 的 line 白名单扩第三线 `material`(第 74 次 channel 线同款:CreateCmd 校验+actualOf/actualOfRange 分支+字典);
- 实绩契约:SalesApi 扩 `materialSalesTotalByMonth(orgId, ym)` / `materialSalesTotalBetween(orgId, begin, end)`(按 sales_order.created_at 聚合 total,剔除 2/3/4 废退单——与 listByDecorationOrder 同口径),实现在 addon-sales,TargetService 只依赖契约零直查;
- 目标拆分页=Targets.vue 同族新页或工作台内嵌(拍板项);户数目标 V1 不做(金额先行,户数随 V2——target_plan 单金额列,诚实边界)。

### 3. 工作台框架 + 主材销售工作台(dashboard V2 子域)

- 归属:**addon-dashboard V2 子域**(与驾驶舱同族,复用 report SPI/组件语言/权限);码段 390100–390150 小段;迁移 V1902+(如需;判定推导零新表,预计**零迁移**);菜单「主材工作台」(/dashboard/material,权限闸走 addon.yml api 段);
- 页面结构(与 D4 组件语言同族,不触发 huashu 三方向——驾驶舱已定调,工作台=同族延伸;若拍板要求独立视觉另走):
  - 顶部:月份选择+组织范围(公司/分区/部门,S2 下拉);
  - KPI 卡族:本月主材业绩(达成/缺口/时间进度)/本月跟单户数(已跟进/临近签约)/异常预警数(逾期跟进/目标落后部门);
  - 五阶段漏斗条(装修单维度:各阶段单数+金额,点击下钻跟单列表);
  - 跟单明细表(客户/装修单/设计师·部门/阶段/停留天数/报价单数/操作→跳转既有详情页);
  - 目标拆分入口(target 主材线月份拆分视图);
- 端点:GET /api/dashboard/material/summary(聚合)+ /material/tracking(跟单列表,分页/筛选)——全部只读聚合,归 /api/dashboard 既有 prefix;
- 设计师工作台/收款工作台:**W3 候选**(框架同构,数据源不同;等主材工作台验证框架后复制模式)。
