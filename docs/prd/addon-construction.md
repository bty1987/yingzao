## 业务闭环(一句话)

装修单进入施工期后,以**放线**为开工点火:创建施工单(与装修单 1:1)并按组织节点模板快照生成**节点排期**,施工按"节点 0 初始→1 开工→2 完工"推进(开工/完工受款项比例闸约束),人员/日志/图纸/档案全程留痕,最终以**验收(合格→完工)**触发装修单工程线收口;关键动作经领域事件通知责任人。

## 用户与场景

| 角色 | 场景 | 高频动作 |
|---|---|---|
| 监理 | 施工执行 | 申请放线、排期节点、开/完工节点、进场登记、巡检日志 |
| 放线员/小组 | 前置勘测 | 领取放线任务、上传放线结果(成功/失败) |
| 项目经理 | 团队与费控 | 指派工人、开放工费、辅料限额管理 |
| 工人 | 干活与口碑 | 进出场打卡、被评分 |
| 客户 | 参与验收 | 工人评分(微信链接)、验收确认 |
| 分公司经理 | 交付管控 | 节点免检、验收、看进度全景 |

## 核心流程(状态机文字版)

1. **放线**(开工点火):申请(查重+须有报价)→ 0 排队;排期(指派小组+起止时间,时间冲突校验)→ 1;成功 → 2 并**创建施工单+按组织节点模板快照生成全部节点排期**;失败 → 3(通知设计师)。补录=显式用例(带审计),不再是无状态后门。
2. **节点推进**:开工(前置=节点 0 态+款项比例闸:装修款/销售款达组织配置阈值)→ 1;完工(postcheck/fincheck 同闸)→ 2;工费旁路 1→3(未完工先开放工费,3 可直接 2);删除仅 0 态。
3. **执行留痕**:工人指派(节点未开工拒)、进出场流水(enter→leave 正序)、施工日志(自动进出场判定)、图纸/档案(模板-项-选项三层,限额上传)。
4. **验收收口**:前置=收款比例≥组织配置阈值;验收提交 → 装修单工程线 1→2 完工 + 施工单 process 置竣工;检查项走**可配置模板**(一行一检查项),含合格/不合格分支;发布 `ConstructionAcceptedEvent` → 通知+账目联动由订阅方处理。
5. **费控**:工费上限(‰元)在累计时拦截;辅料限额台账随出库联动(真业务在 addon-inventory,本 addon 只持台账)。

## 闭环校验

- 闭环起点:装修单工程线 0→1(开工)由放线成功触发;闭环终点:验收完成 → 工程线 2 完工。
- 异常路径:重复放线(260001);无报价放线(260002);节点非法流转(260003,非 0 开工/非 {1,3} 完工/已开工删除);款项比例不足(260004/260005 对应装修款/销售款);未开工指派工人(260006);验收比例不足(260007);全部双语 i18n。
- 金额/比例/工期**单一口径**:金额 ‰元、比例 ‰、工期 ‰天——废弃老系统 /1e6 漂移与分/‰元混用(§11/§13)。

## 非目标(本期不做)

- **主材计划**(两层模型:组织级规则配置+订单实例+履约回填)——规则配置归 addon-basedata,实例联动另立设计(rules §7 设计优秀,单独立项);
- **辅料出库/审核**——真业务在 addon-inventory,本 addon 仅持限额台账;
- **售后三件套**(投诉/回访/保修)——老实现为裸 CRUD 无保修期计算,V2 重设计后另立 addon-service(待划界);
- **质检线**——V1 合并为"施工团队指派",真质检流 V2 再议(rules §15.4);
- **返工单**(带费用/工期联动与审批)——V2;
- 钉钉/微信推送、survey 自动派发、合伙人三角指派——通知走内核通知中心,其余沉插件。

## 验收标准

- [ ] 放线:排队→排期→成功全链走通;时间冲突校验生效(修正老系统失效 SQL);成功后施工单 1:1 创建且节点排期快照完整;失败路径通知设计师。
- [ ] 节点:0→1→2(+3 旁路)合法流转;开工/完工款项比例闸按组织配置生效;免检(如有)必须留痕操作人;非法流转 260003。
- [ ] 排期:计划时间 = 节点模板工期 × 前后置累加,‰天单一口径;重排(锚点)可用;后端排序。
- [ ] 验收:检查项模板可配置;收款比例门槛生效;提交后装修单工程线 1→2;不可重复验收。
- [ ] 留痕:进出场流水正序校验;日志/图纸/档案归属校验(任何操作校验 org 归属,修复老系统裸删)。
- [ ] 事件:节点开完工/验收发布领域事件,通知中心触达责任人(插件消费事件调内核 API 姿势)。
- [ ] i18n 双语完整;错误码全落 240000 段;迁移 V600+ 在 addon 独立 location;零公司判断。
