# PRD - addon-target 经营目标

> 状态:V1 实现随本文件同轮交付(2026-10-21,第 73 次;docs/08 组织树 S3 首个消费方)
> 老系统参考:docs/07 §2.1(fl-yy 三套目标模型)——「战区分部目标计划/阶段目标/经营目标报表」的营造映射

## 业务闭环(一句话)

管理层为组织树上任一节点(公司/分区/部门)按月设立经营目标(业绩线=签约额),系统按该节点子树聚合实绩、实时给出达成率——把「达成率的分母」从 Excel 变成一等实体。

## 模型(docs/07 三模型的 V1 映射)

| docs/07 模型 | V1 落点 | 说明 |
|---|---|---|
| 战区分部目标计划(月目标) | `target_plan`(节点×月份×业绩线唯一) | 目标挂树上任一节点;月目标独立存在 |
| 阶段目标(月内切阶段) | **V1.1 后置**(表结构预留 line 维度) | 月初淡月末冲的阶段立标 |
| 经营目标报表+提交留痕 | `target_submission`(调整留痕:旧值→新值+说明+操作人) | 月中改目标不再有争议 |

## 状态机与守卫

- plan 无状态机;启/停用(停用后达成率分母不出现该目标);
- 守卫:同节点同月同线唯一(370003);金额>0(370004);月份格式 yyyy-MM(370005);节点必须存在(370006,树上任意节点,V1 不校验层级标签);
- 调整=改额并**强制写留痕**(old→new+remark);
- 删除保留(错录场景);常规修正走调整。

## 实绩与达成率(V1 口径,诚实声明)

- 业绩线 V1 仅 `contract` 签约额:实绩 = 装修单 `status ∈ {3,4,7,8}`(签约/重签/决算/完工)且**首签月=目标月**的 `Σcontract_total`(经 DecorationApi 契约聚合,禁直查他域表;重签同单只计一次);
- **聚合范围 = 目标节点子树**(scopeOrgIds,复用 S1 OrgScopeService 基座);
- 🔴 **V1 诚实边界**:业务单据目前只有公司级 org 归属(装修单挂登记组织),**分区/部门节点的实绩恒为 0**——分区/部门达成率需业务单据的部门归属模型(docs/08 S2 之后演进),V1 允许建分区/部门目标(分母就绪)但分子待 V2,看板明示「实绩口径:公司级」;
- 渠道/回款等其他业绩线:V2(V1 line 字段枚举位预留)。

## 端点(/api/target,菜单闸 require /target/plans)

- GET /plans?node=&ym= —— 列表(节点名/目标/实绩/达成率实时聚合);
- POST /plans —— 建目标;
- PUT /plans/{id} —— 调整金额(强制留痕;body: amount/remark);
- POST /plans/{id}/status —— 启停;
- GET /achievement?node=&ym= —— 单节点达成率(看板数据源);
- DELETE /plans/{id} —— 删除(错录场景)。

## 错误码段

370000-370099 独占(370001 参数/370002 不存在/370003 同节点同月同线已存在/370004 金额须为正/370005 月份格式/370006 节点不存在)。

## 非目标(V1 不做)

阶段目标(月内切阶段)、渠道/回款业绩线、分区部门实绩归属(待业务单据部门归属模型)、激励联动(addon-member/战报)、驾驶舱页面(属 docs/06 专题,本插件先供数据)。
