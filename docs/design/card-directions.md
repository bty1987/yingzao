# 匿名名片页 /pages/card/detail · 六候选方向卡(第 101 次,R7)

> 任务:营造 C 端(web-mp uni-app H5)匿名电子名片页——访客免登录,浏览顾问名片+相册,提交留资(姓名/电话/留言)。
> **品牌语境已定档**(2026-10-11 方向三「东方纸墨极简」,见 `direction-approved.md`):纸白 #FAF9F5 / 墨黑 #1A1A18 / 朱印红 #B03A2E 唯一点缀 / 宋体 display / 8px 材分模数 / 方角 / 细墨线 / 朱印方章。六候选均为**该语境下的诠释**,差异在骨架与气质,不在品牌色。
> 输出:390×844 H5 单页(滚动长页),每方向一个完整可交互 HTML(`card-dir-*.html`)。
> 数据契约(来自 R6 后端):GET /api/c/cards/{token} → userName/userPhoto/phone/wechat/industry/profession/address/info/photos[];POST …/notices {name,phone,comment} → {noticeId,duplicate};错误 280103 停用/280104 非法/280109 令牌无效/280110 频次。

## form 五问(共用)

- **叙事角色**:一次「认识你→看作品→信任你→留下联系方式」的个人介绍旅程;
- **观众距离**:近——个人对个人的名片,亲切克制,不过度推销;
- **视觉温度**:暖纸+墨,有手艺感与可信感(装修=手艺行业);
- **容量**:低-中——8 个名片字段+6 张相册+3 个表单字段,留白要足;
- **视觉母题**:帖/印/墨线(品牌典出《营造法式》),各方向各自转译。

## 六候选

### C1 · 名帖双框(最佳设计师|陈幼坚——东情西韵)

- **借的**:双线细框(外粗内细)锁住整版;宋体大字×无衬线小字的横排混排;一枚朱印落在姓名旁;留白中信息分组用极细线,不用卡片容器;英文小标宽字距(YINGZAO)。
- **主角素材**:朱印字头像(「沈」字方章)+相册图位。
- **骨架**:整页是一张**竖式名帖**——顶部双线框内:头像+姓名大字+职业行;框外:相册横滑条;底部:留言笺(表单嵌入帖尾)。
- **胆量花在哪**:整页只有一层「帖面」构图,零卡片零圆角,信息全靠墨线与留白分组。
- **form 来自内容的哪里**:名片本身是「帖」——中国传统递帖见礼的当代转译。

### C2 · 原生名片工具(现实参照|iOS 通讯录名片页)

- **借的**:头像居中偏上是唯一焦点;**动作行常驻**(拨打电话/复制微信/留言三键);信息按组留白分行(无框线卡片);大字姓名+小字职业层级;表单用 bottom-sheet 呼出。
- **主角素材**:朱印字头像+相册小图行。
- **骨架**:**功能优先**——头像区→三键动作行→信息组→作品横滑→底部固定「我要留言」主按钮。
- **胆量花在哪**:把「工具效率」做到极致——访客 3 秒内可拨号/复制/留言,装饰退到最低。
- **form 来自内容的哪里**:名片页的本职是「联系」——通讯录是数字名片的原型。
- 参照说明:基于对 iOS 通讯录卡片页的长期记忆归纳,未截图(本机无 playwright),规则按记忆拆解。

### C3 · 图纸档案(秒数轮盘|App 分区 6 号 Topo Outdoor → 等高线/图纸诠释)

- **借的**:羊皮纸米底上极淡的**墨线等高线→户型/放线线稿**纹理(≤8% 存在感);数据面板式信息呈现(大数字+小标签);面板浮于纹理之上;一条高对比强调线(朱印红)做「动线」。
- **主角素材**:户型线稿纹理(SVG 程序化)+相册图位+面板数字(从业年限/在施工地/交付数量)。
- **骨架**:**档案页**——顶部姓名小帖+中部「服务档案」数据面板(三个大数字)+案例图格+底部固定留资面板。
- **胆量花在哪**:淡等高线纹理铺满全页,把「装修=营造施工」的行业质感做成背景语言。
- **form 来自内容的哪里**:营造=施工图纸,等高线→户型墨线是题材内的直接转译。

### C4 · 作品画册(最佳设计师|原研哉×观夏 To Summer 移动端参照)

- **借的**:作品摄影当主角(大图呼吸感,一屏一图);衬线小标题+无衬线正文的器物式排版;内容>容器——无卡片边框,图就是结构;克制的单点缀色。
- **主角素材**:相册大图(占屏 70%+),名片信息压缩成图间注脚。
- **骨架**:**画册**——满版作品图纵向慢节奏滚动,姓名/职业以竖排题签浮于首图,信息与表单藏在页尾「落款」区。
- **胆量花在哪**:名片信息只占 20% 篇幅,作品占 80%——「看作品再决定」的信任逻辑。
- **form 来自内容的哪里**:装修行业客decision=看真实案例,作品即名片主体。
- 参照说明:观夏移动端纸感电商的长期记忆归纳,未截图。

### C5 · 书帖版心(最佳设计师|吕敬人——书装版式)

- **借的**:版心不居中——上提靠左,天头小地脚大;竖排姓名题签;朱砂红只用一处(一方印);行距 2 以上;旁注小字栏。
- **主角素材**:竖排大字姓名+朱印+相册图位。
- **骨架**:**一叶书**——首屏如书叶(竖排姓名+职业旁注),下部横排相册与信息,表单为页末「跋」。
- **胆量花在哪**:姓名竖排占半屏,像一册手递的名帖。
- **form 来自内容的哪里**:《营造法式》古籍版式基因的品牌典出。
- 样张:`assets\style-specimens\east\01-lu-jingren-bookcraft.jpg`(条目在档)。

### C6 · 主材色卡(秒数轮盘|East 分区 6 号香港街招**语境不兼容顺延**7 号节气色谱)

- **借的**:**色条即导航**的版式动作——每个案例配一条主材色带+传统色名(缃叶/海天霞/琥珀…),当前案例色条升高变宽;大字标题局部换色(朱砂);暖纸底+墨色,纹样克制。
- **主角素材**:相册图位+每案例的三色主材色卡条(真实内容:装修案例确有主材色板)。
- **骨架**:**色谱页**——姓名帖→案例列表(图+色带+色名)→页尾留资;右缘一条全程竖色带由案例色渐次铺成。
- **胆量花在哪**:传统色名给每个案例「定调」,色带不是装饰而是案例的主材色档案。
- **form 来自内容的哪里**:装修选材看色板——色卡是装修行业的真实物料。
