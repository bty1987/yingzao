# 第 84 次运行总结(2026-10-25):A4 报价项库+保价重算

> docs/11 A 批第四项:报价项库(单价主数据)+ 价格快照时间线 + 按时间点回填明细——老 data.quotationItem/quotationPrice/updateQuotationForPrice 三件套的行业中性回归。

## 一、做了什么

### 1. V404 迁移(两表一列)

- `quotation_item` 报价项库:组织级单价主数据(name/unit/subtype/price 当前价/status/remark),**uk(org_id, name)**——单价库是模板数据,同名单价必为维护事故;老 data.quotationItem(品类/大类/小类/工作类型多维)行业中性收敛四列;
- `quotation_item_price` 价格快照时间线(item_id/price/operator_id/created_at,idx(item_id, created_at)):append-only,建项即插首条(老 addQuotationPrice 初始快照 createTime 硬编码 2015-01-01 的 hack 不迁——生效时点=建档时刻);
- `quotation_function_item` 加 `catalog_item_id`(null=自由行,老 quotationItem 挂接同语义)。

### 2. 调价=价格唯一写点

POST /catalog/{id}/price:插新快照+同步当前价;**同价幂等零写入**(防重复点击刷快照)。老 updateQuotationItem 直改当前价与快照脱钩、updateQuotationPrice 可改历史价(审计坑)均不迁——历史 append-only,写错走再调一次。

### 3. reprice 保价重算(老 updateQuotationForPrice 语义)

- POST /quotations/{id}/reprice {time 可空}:按时间点取各挂接项最后一条快照回填明细行单价,**复用 recalc 服务端重聚合**;time 缺省=now(重算到最新价);
- 自由行/该时点无快照行跳过(老 quotationItem==null / quotationPricePO==null continue 同语义);
- 仅编辑态可重算(requireEditable;锁定 230003);**未来时点拒 230164**;
- 返回回填行数+track action=reprice(带时点与行数)留痕;老三价(addPrice/unitPrice/subPrice)收敛单 price 列。

### 4. 明细挂接

addItem 带 catalogItemId 建立挂接(仅创建时,update 不换挂——换挂=删行重加);price 缺省带库价(传了用传入价);停用项拒新挂接 230162,**存量行重算照常**(快照在,与老查询不看 item status 同口径)。

### 5. Web

- Catalog.vue 新页:分页检索+新建(带初始单价=首条快照)/编辑(档案与价格分离)/调价弹窗/价格历史抽屉/启停二次确认;菜单 /quotation/catalog + catalogStatus 字典;
- Quotations.vue 三处:明细加项弹窗「报价项库」远程搜索下拉(选中带出名/子类/单位/单价)+重算按钮与时点弹窗(编辑态显)+明细行「库」挂接徽章;trackAction 字典加 reprice;bump 0.5.0。

## 二、自主决策记录

1. **报价项库归 addon-quotation 本域**(非 basedata):docs/01 过堂表早已裁定「定额库/报价项→addon-quotation」,本轮兑现;行业中性收敛只留 name/unit/subtype/price,品类维度随定额子域 V3;
2. **调价唯一写点+同价幂等**:老「档案编辑与快照双轨」是价格漂移根源,收单点;
3. **挂接仅创建时建立**:update 换挂=删行重加(低频显式),避免行价与挂接项的状态空间爆炸;
4. **停用项:拒新挂接、存量重算照常**:停用与「价格失联」是不同运营动作(与 supplier 310058/059 两态同构思想);

6. **错误码 230160-230164**:主段延续(230157 后顺延),V403 的 231xxx 段是增减线独立段不混用。
