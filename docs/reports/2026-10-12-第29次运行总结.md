3. **🔴 深链接失效修复(web/src/main.js,真产品 bug)**:原启动顺序 = 先 mount 后注册动态路由,直接访问/刷新任何业务 URL 时初始导航命中 pathMatch 兜底被甩到第一个菜单(/basedata/goods)——**用户浏览器刷新即复现**;修为 `loadAddons().then(register → mount)`(清单拉取失败照常挂载兜登录页);截图脚本因全页 goto 每页都是"深链接"才暴露此雷;
4. **🔴 菜单 path 与组件文件名失配修复(三个文件改名)**:registerAddonRoutes 约定 = 菜单 path 末段 PascalCase 对应 `views/<addon>/<Page>.vue`,`Decorations.vue`/`SalesOrders.vue`/`SalesSettlements.vue` 与 path(`orders`/`settlements`)单复数失配 → 三个菜单(装修单/销售单/销售结算)路由从未注册,直连/刷新必甩走;菜单 path 是 RBAC 授权契约不可改,**组件文件改名对齐约定**(git mv 三处,组件仅被 glob 动态引用零其他引用);python 脚本全量盘点 23 菜单 path,失配清零;
5. **app index.html viewport 泄漏修复**:uni-app 官方模板 document.write 拼串把 `, viewport-fit=cover` 写成可见文字(meta 已闭合);修为拼进 content 属性内;
6. 途中踩坑:IAB 浏览器 Playwright click 对该页按钮可达性超时,改 `cua.click` 坐标路径;UI 登录后表单重置疑云,改页面内 fetch 登录+写 localStorage(等效 token 注入)。
