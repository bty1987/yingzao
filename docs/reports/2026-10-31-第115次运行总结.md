## 四、自主决策清单

| 决策 | 理由 |
|---|---|
| 单表 yz_audit_log 双 category(老两表合一) | V1 注解 opt-in 量级小;两查询面/两 Web 页语义不变 |
| 注解 opt-in 替代老全请求拦截器 | 查询/读端点天然零噪声;logFlag 三档配置面随 operation 表不迁 |
| 脱敏走 Jackson 树级递归 | record Cmd 参数不是 Map,首版递归不进=密码明文(自查抓出);树展开后全形态覆盖 |
| REQUIRES_NEW+全吞异常 | 老 safeAddActionLog 语义原样继承;业务回滚审计仍在 |
| 踢出留痕(老系统不留痕) | 审计价值最高事件之一;挂 evictUser 触达点(停用/重置密码) |
| purge 计划恒链式续期 | retention=0 执行空转但链条不断,再开启无需重启 |
| 登录失败行 org_id 尽量回带 | 密码误但用户存在→真实 org(暴力破解审计口径);用户不存在=0 且 logins 查询含 org 0 行 |
| 归档分表/采样/ThreadLocal bind 不迁 | 量级判断+SpEL 直接取参零 ThreadLocal 泄漏面;V2 随量级再评估 |
| Web 管理页不走 huashu 三方向 | 管理查询页族判例(Plans/Events/Users 同判),既有纸墨体系延伸 |
| Redis 模式全量未跑 | 本轮零 TokenStore 改动(F2 已双模式);内存全量+enforce 覆盖 |
