## 八、教训沉淀

1. **pymysql 占位符三字符律**:`%%`=字面百分号、`%s`=占位符,LIKE 模板里两者混排时逐个数(`'%%'`+`=%s`,不可写成 `%%s`)——一跑中崩即此;
2. **段脚本中崩残留=下轮同段前置炸**(残留 target 使 W1 段 370003)——段首清理必须覆盖「本段可能残留的全部键」,且崩后手动确认段首清理键覆盖崩溃窗口;
3. **形状正则≠语义校验**:`\d{4}-\d{2}` 放行 2026-13,DateTimeFormatter 解析期炸 110000——入参守卫两级都要(第 104 次 yearMonth=2026-13 先例在 decoration 侧,W2 侧照抄形状漏了语义);
4. **fat jar 增量陷阱+keepalive 复活循环**:mvn package 不带 clean 时 yingzao-app 显示 SUCCESS 但 fat jar 不更新(嵌套 jar 未重打包);keepalive 双实例在杀 java 后 2s 内复活——清场必须「先杀 python 后杀 java+循环至双归零」(第 83 次教训原文应验第 N 次);
5. **探针先行**:全量冒烟前用 python urllib 探新端点,当场抓 yz_user 列名错(display_name 非 name)——真缺陷在冒烟首跑前即修,省一轮三跑迭代。
