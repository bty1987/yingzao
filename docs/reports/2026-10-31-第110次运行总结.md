### 4. 🔴 冒烟前自查抓出真产品 bug:yz-grid 组件 @tap 事件链在 H5 断裂

- **现象**:浏览器实测宫格点击不跳转(通知 cell 的 @click 链正常,排除自动化点击问题);
- **根因**:uni-app H5 编译器把**组件标签**上的 `@tap` 重写为 `onClick` 监听(编译产物 `onClick: $options.goGrid`),而 yz-grid `emit('tap')` 时 Vue 查 `onTap` prop——**落空,链路断裂**;mp 端 bindtap 收的才是 'tap' 事件。对照 playground 同款绑定——**第 109 次只验了宫格渲染未验点击,此 bug 带病入仓**;
- **修复**(yz-grid.vue):gcell @tap 保持(视图层 uni 已做 tap→click 归一),`emit('tap')+emit('click')` 双发——H5 命中 onClick、mp 命中 bindtap,两平台各命中其监听,另一名无监听者不双触发;
- **实证**:修复后 el.click()→/pages/leads/create ✓、请假格→/pages/leave/leave ✓(整页 reload 后验证,vite HMR 对 script setup 热替换不可靠系第 109 次教训);双端 build 重新绿。

## 二、自主决策记录

1. **require 单字段=菜单 path 或 capability(并集语义)**:app 页面的 api 闸是菜单型(如 POST /api/customer/leads→/customer/leads),纯 capability 字段与实际闸不匹配;沿 Api.require 既有词汇(菜单/capability/authenticated)取其最自然的子集,一个字段覆盖两类授权身份;
2. **内核页面(通知)保留固定 cell 不进 addon.yml**:core 无 addon.yml 也不该伪装插件;通知是 app 壳设施(徽章数据源同源),与 tabBar 同层;宫格只承载插件条目;
3. **我的机会不占格**:已在 tabBar(机会 tab),配置化再发一格是重复 UI;addon 作者视角 tabBar 存在性是 app 壳决策,插件只声明自己的功能入口;
4. **yz-grid 双发 tap+click 而非改事件名为 pick**:保持 uni 生态语义(格子激活就是 tap/click);mp/H5 各命中其一不双触发,双端行为一致;
5. **enforce 加 mobile require 静态校验**:槽位 require 拼错的表现是「所有非 admin 用户格子静默消失」,admin 旁路无法发现——静态校验是唯一廉价闸;
6. **playground 临时入口移除**(页面保留):第 109 次注释既定计划,工作台回归纯配置驱动。

## 三、踩坑记录(下轮必读)

1. 🔴 **uni-app H5 编译器把组件标签 @tap 重写为 onClick**:自研组件若 emit('tap'),父组件 @tap 在 H5 静默失效——**自研组件跨端事件契约=双发 tap+click**(或避开 tap/click 命名空间用业务事件名);检查法=看 vite 编译产物(`curl http://localhost:5176/src/<file>.vue`);
2. **vite HMR 对 script setup 组件热替换不可靠**(第 109 次教训复现):hash goto 不重载模块,必须整页 reload 再验;
3. **CUA 坐标点击偶发不落地**(通知 cell 能点、同页 gcell 点不进,elementFromPoint 证明元素在位)——自动化器怪癖非产品;程序化 el.click()/dispatchEvent 是可靠替代,真实用户点击不受影响;
4. **IAB 浏览器 getByPlaceholder 对 uni-input 落空**:真 input 在 uni-input 内部,姿势=`locator('uni-input input').first()/last()`(第 109 次 `.yss .kw input` 同款根因);
