## 一、做了什么

### 1. TokenStore 接口化(内核 auth 包,四件)

- `TokenStore` 类→**接口**:PRINCIPAL_USER/PRINCIPAL_CUSTOMER 常量与 `Token` record 留接口内(全部既有引用面 `TokenStore.Token`/`TokenStore.PRINCIPAL_*` 零改动);`issue(2参)`/`issueCustomer` 降为 **default 方法**归一到 4 参 issue,双实现只写核心三方法;
- `InMemoryTokenStore`(缺省):spike 逻辑原样迁移,唯一变化=TTL 经构造入参(缺省 12h=存量行为,且 `yingzao.auth.ttl-hours` 不再出现「调了没反应」的静默陷阱);
- `RedisTokenStore`(`yingzao.auth.store=redis` 启用):会话键 `yz:auth:token:{token}`→JSON 载荷( expiresAt 用 epoch 毫秒 long,零 JavaTime 序列化依赖),TTL=会话期(签发即定不滑动,键过期即会话失效);踢会话索引 `yz:auth:user:{userId}`→token 集合(仅员工主体入索引);**签发走 Lua 单脚本原子写**(SET+条件 SADD+PEXPIRE,防「令牌已活而索引未落」的踢不掉窗口);verify 读键+expiresAt 双保险(防时钟偏移);**redis 不可达=失败关闭**(异常上抛,鉴权宁拒勿放);键前缀 `yz:auth:` 与宿主机共存使用者隔离;
- `TokenStoreConfig`:`@ConditionalOnProperty` 双 Bean 装配(memory=matchIfMissing 缺省 / redis 显式),F1 惯例 `@Value` 构造注入(`yingzao.auth.store`/`yingzao.auth.ttl-hours`)。

### 2. 配置与部署三件

- yingzao-core pom 加 `spring-boot-starter-data-redis`(Lettuce 懒连接:内存模式全程零连接零行为变化);
- application.yml 增 `yingzao.auth.store/ttl-hours`(YINGZAO_AUTH_STORE/YINGZAO_AUTH_TTLHOURS 环境变量)+ `spring.data.redis` 段(YINGZAO_REDIS_HOST/PORT/TIMEOUT,connect-timeout 3s 防故障时请求挂 60s 默认超时);
- docker/docker-compose.yml 增 redis 服务(redis:7-alpine+appendonly+healthcheck,**不发布 6379 到宿主机**防与本机既有 redis 撞端口),app 增 `YINGZAO_AUTH_STORE: ${YINGZAO_AUTH_STORE:-memory}` 与 `YINGZAO_REDIS_HOST: ${YINGZAO_REDIS_HOST:-redis}`——compose 部署切 redis=一个环境变量。

### 3. 🔴 自查抓出真缺陷:C 端令牌误入踢会话索引(冒烟前修)

## 二、自主决策记录

1. **失败关闭(fail-closed)而非 fail-open**:redis 不可达时 verify 异常上抛→全 API 500,而非放行——鉴权面宁拒勿放;连接超时 3s 配置兜底防请求长挂;与内存后端「查无会话=401」语义在文档中显式区分;
2. **C 端令牌不入索引**(冒烟前自查修出):Lua 条件 SADD 比应用层判断更原子,且语义下沉到脚本单点;回归锚进 smoke_redis_auth.py;
3. **ttl-hours 双实现同语义**:内存实现也吃该参数(缺省 12=存量),消灭「配置只对一边生效」的静默陷阱——比「内存写死 12h」多一行代码换配置一致性;
4. **evictUser 顺序=先删令牌后删索引**:中断窗口只留悬空索引项(DEL 幂等可重放,令牌键自身 TTL 兜底);反向顺序会产生「索引没了但令牌还活着」的真踢不掉窗口;
5. **Lua 仅用于签发**:签发必须原子(半签发=安全洞);evict 用 SMEMBERS+批量 DEL 即可(非原子无安全后果);不为对称而对称;
6. **compose redis 不发布宿主端口**:内网互通即可,防与本机既有 redis(6379 已被占)撞端口;compose 切 redis=部署侧一个环境变量;
7. **spring.data.redis.password 不进 yml 缺省段**:空串密码在部分客户端会发 AUTH 命令报错,密码场景由部署侧显式补(注释已写);
8. **smoke_all 步数 2663→2667 不回写基线断言**:漂移来自早段历史数据累积(前轮同款),零失败不属产品变化;
9. **不新增错误码/i18n/迁移**:认证存储是内核设施,无业务码面;F2 零 DB 变更(Flyway 零触达)。
