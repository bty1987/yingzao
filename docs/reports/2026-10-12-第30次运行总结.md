# 2026-10-12 第 30 次运行总结:管理后台改倒 L 布局 + 修复业务页脱离布局的根因(用户反馈驱动)

> 用户反馈:"菜单和页面布局参考原有倒 L 的方式,目前进入到具体页面就无法访问其他页面内容"。核查证实这不是视觉偏好问题而是**功能 bug**:业务路由从未挂进布局,任何业务页面都不存在导航。本批修复根因 + 按用户要求重排为倒 L(左侧分组菜单+顶栏),Web 十一截图全部重截。web npm build 全绿。

## 一、根因与修复

1. **🔴 业务页脱离布局(功能 bug,用户报告的现象根源)**:`registerAddonRoutes` 用 `router.addRoute('/', {...})` 按父名挂载,但 `'/'` 路由**没有 name**——vue-router 4 解析不到父路由时把业务页面**注册成顶层路由**(dev 警告被淹没),页面脱离 Layout 渲染:顶部横导航从未在业务页出现过,"进入具体页面就无法访问其他页面"。修复:`'/'` 路由显式 `name: 'layout'`,`addRoute('layout', ...)` 挂为布局子路由——顶栏/侧栏在全部业务页常驻;
2. **倒 L 布局重排(Layout.vue 重写,按用户拍板)**:左侧 220px 竖向菜单(白纸面+右缘细墨线;brand=朱印方章「法」+宋体营造;菜单按插件分组,组名=插件名淡墨小字;激活项=左缘朱印条+纸深底;审批中心置顶、角色权限归"系统管理"组仅 admin 可见)+右侧顶栏(宋体页题+通知铃+用户名+退出)+内容区。菜单 24 项竖排分组,横排溢出问题一并消解;视觉仍守方向三 token;
3. 上一批的深链接修复(main.js 先注册后挂载)与组件改名与本批修复互补:深链接 → 初始导航命中;name 挂载 → 命中后包在布局内。
