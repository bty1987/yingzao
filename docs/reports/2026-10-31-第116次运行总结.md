## 八、教训沉淀

1. **H2 MODE=MySQL ≠ MySQL**:date_sub/date_add(interval) 不支持——生产 SQL 先过探针再铺测试,别按「兼容模式」想当然;
2. **JdbcTemplate 的 SQL 传入点有两处**:PreparedStatement 在 prepare 时,Statement 在 executeQuery(sql) 时——方言垫片只拦 createStatement/prepareStatement 会漏掉 StatementCallback 一半执行路径;
3. **动态代理接口集必须递归收集全接口**(PreparedStatement extends Statement,单接口代理在调用方强转处炸);
4. **payloadAs 的同名字段子集陷阱**:SubmittedEvent 与 FinishedEvent 前 7 字段同名,payloadAs(FinishedEvent.class) 对 Submitted 载荷「成功」反序列化(result=0)——按事件类型过滤而非仅按 id;
5. **retry() 与 cancel() 的状态闸不同**:retry 接受 2+3,cancel 仅 0+2——凭直觉写断言必错,先读生产注释。
