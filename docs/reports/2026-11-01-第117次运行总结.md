## 八、教训沉淀

1. **yz-image-grid 双拼 rpx 带病入库**(R12):`:style` 里 computed 已含单位再拼后缀=非法值,格子宽高静默失效——playground 因回落自然宽「看起来正常」;组件验收必须断言计算样式而非仅截图;
2. **uni-app H5 页面栈**:mid-flow goto() 同路由会叠实例,截图与 DOM 分属两层全错位——浏览器实测中途禁用 goto,统一 reload 或新 tab 重置;
3. **IAB 点击管线三连**:uni-input/uni-text/yz-grid 格对 Playwright actionability 全不可见(hidden),CUA 坐标点击+截图对位是唯一稳定路径;cua.scroll 会超时,程序化滚动走 evaluate(window.scrollTo);
4. **假 PNG 字节**(仅文件头+文本)uni.downloadFile 成功但 uni-image 渲染空白——冒烟素材与截图素材要用真图(zlib 手工造真 PNG 五行代码);
5. **business id 两义**:construction_order.id(自增)≠order_id(装修单),biz 挂接一律锚 order_id——本轮回写 biz_id=642 险些错锚。
