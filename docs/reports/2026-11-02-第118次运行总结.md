## 八、教训沉淀

1. **页面级 ref 漏定义=静默白屏变体**:模板引用未定义的 `logged`(undefined),`!logged` 恒真恒显未登录态,load() 赋值抛 TypeError 被 uni 吞——页面初写后必须 grep 模板变量与 script 定义双向核对(finance 有/album 漏,同轮两页不一致);
2. **vite dev on-demand 编译+`-I` python 隔离模式**:文件改动后 reload 首编译慢(5s+);`python -I` 隐含 `-E` 会忽略 PYTHONUTF8/PYTHONIOENCODING,GBK 控制台打印 ✓/✗ 必炸——跑冒烟脚本用 `python -X utf8`;
3. **冒烟段首清理会删跨轮遗留文件**(by design):浏览器实测数据依赖上轮遗留图时,先确认文件存活(本轮回写新图),占位兜底正是为此设计;
4. **BizException → HTTP 200 + JSON**:字节流端点异常时 downloadFile 仍 200(拿到 JSON 体),前端 `<image>` 渲染失败落占位——fail 静默但体验兜底成立;后续若需精确错误可让 downloadFile 校验 content-type。
