# 第 86 次运行总结(2026-10-26):A6 三口径表算法

> docs/11 A 批第六项:半包配比/整装满减/包干增项三分支——老 DecorationMidpack/Holonomy/Inclusive 三 Service 的行业中性回归(V503 三表+CaliberService,口径与款线解耦)。

## 一、做了什么

### 1. V503 三表(decoration_caliber_{midpack,holonomy,inclusive})

每单每型一行(uk org+order):入参(配比/费率/折扣/增减四项)+快照(报价拆分)+产物(主材配额/服务费/推导总额)+status(0 初始/1 确认)。金额全厘;配比/费率统一 **ppm(百万分比,200000=20%)**——老 ppm/万分比/千分比/百分比四制式并存不迁(显式文档化)。

### 2. CaliberService:统一门禁+三算法

- **统一门禁**(老三表 make 前置链一致,收敛一处):主单合同线 status∈{0,1,2,4}(签约/决算/完工锁死 250002)+默认报价存在且定稿锁定(经 QuotationApi 契约 250030)+口径行未冻结(重算仅初始态 250031);老「订单活动锁定」门禁不迁(活动域未建——诚实边界);
- **Midpack(半包)**:主材配额=工程基础额×配比;服务费=主材配额×费率;配比 0=手填主材额(老语义);material_origin 初始推导额留重算对照;
- **Holonomy(整装满减)**:折上折(工程额按基数取整**余数不打折**,老算法)+管理费可选跟随折扣+主材配额同构;
- **Inclusive(包干)**:推导总额=报价总价+常规增减全额+MET 增减按 **met_flag 行参数三分支**(UPMET 仅正计/DOWNMET 仅负计/COMMET 无条件)——**老公司配置 QUOTATION_EXTENSION_MET_FLAG 收敛为口径行参数,逐单可选**(方林嫌疑收口:公司商务政策→逐单口径);
- make 幂等重建(on duplicate)+confirm 显式冻结;轨迹 action=caliber-{kind}-{action}。

### 3. 契约扩展

QuotationApi 新增 `defaultQuotationBreakdown`(QuotationBreakdown record:undis/dis/manage/carry/tax/total/discount/manageRate/locked)——增方法不破坏既有契约零影响。**首轮实现踩坑:费率项金额(管理/搬运/税)不在主单列**(V401 主单只存三段总额,费率金额在明细行 type=3/2/8 聚合回填)——修为三子查询取明细行合计(BadSqlGrammar→110000 的真因,service 日志栈帧定位)。

### 4. 与款线解耦(诚实边界)

老 make 后 makeDecorationPayment 重建款计划;营造款线=签约 scaleTemplate 拆分,口径表**只产推导指标**(主材配额/服务费指标/包干合同总额),不回写装修单不动款线——Inclusive 推导总额可作签约 contractAmount 输入。增减数据源 V1=手工入参(拓展项域未建,随报价 V3 接入)。

## 二、自主决策记录

1. **口径与款线解耦**:老 make 即重建款计划与营造签约拆款模型冲突(款线在签约时刻建);口径表价值=推导指标与合同价参考,硬接款线=重做签约线;
2. **MET 公司配置→口径行参数**:三分支本质是"每单会碰项怎么算"的商务口径,逐单可选表达力更强;组织缺省可后补 config 列(现缺省 UPMET);
3. **配比 0=手填**(老 Midpack 语义保留):配额手工核定是真实运营场景;
4. **confirm 后无反确认**:口径确认=合同价基准锁定,重做=业务重议(显式排除,与老 servicePaidup 冻结同构);
5. **活动门禁/拓展项数据源顺延**:域未建不硬造,口径入参显式(诚实边界两处,文档化)。
