## 二、自主决策记录

1. **全量校验拒绝制而非跳过错误行**:老导入器「部分成功+静默转换」是脏数据第一根源;批量导入的正确语义是「要么全对要么不给进」;
2. **品类/品牌必须预先存在**:导入器是数据入口不是主数据入口,级联建档会绕过品类树守卫(有子品类停用等);
3. **金额模板用元**:运营填 Excel 的自然单位,服务端 ×1000 转厘——量纲换算收口在服务端一处,模板列头带「(元)」显式声明;
4. **拼音校验而非自动生成**:老系统自动生成产生过 List.toString 方括号脏值;宁严勿错,大写直接报错让用户改;
5. **模板下载走 HttpServletResponse 而非 ResponseEntity**:全仓零 ResponseEntity 先例,servlet API 直写零新依赖;
6. **校验失败走返回体而非异常**:逐行明细是业务结果不是错误栈,260023+data.errors 让前端表格直接渲染。
