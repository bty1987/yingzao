1. **菜单固定业务链顺序(Layout.vue)**:`MENU_ORDER` 固定序 = 系统管理(角色权限,仅 admin)→ 流程协作(审批中心)→ 基础数据 → 营销获客(漏斗顶端)→ 客户档案 → 客源管理 → 报价 → 装修单 → 施工 → 销售 → 库存 → 款项 → 结算;组名沿用插件名;**未登记插件自动追加尾部**(前向兼容,新增插件即插即显);非 admin 自动滤掉系统管理组;

4. **app 端同口径**:App.vue `.card` 与 `.btn-mini` 白底 → 纸色(uni-app 端卡片靠淡墨线成形);
