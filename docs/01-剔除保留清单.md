# 01 - 剔除/保留清单(需求规格书)

> 本清单回答一个问题:**老系统(4666 Java 文件 / 41 模块 / 650 页)里,哪些是装修行业的,哪些是方林的。**
> 它是本项目的需求规格书:每个模块的归属在此过堂,过完堂才允许写代码。

## 判断法

一句话:**"换一家装修公司,这条规则还成立吗?"**

- 成立 → 行业业务 → 进**行业插件套件**(开源)
- 不成立,但有多家公司会需要 → 公司特性 → 进**公司插件**(闭源/按需)
- 与行业无关,所有 ERP 都要 → 通用设施 → 进**平台内核**
- 运营噱头或历史包袱 → **删除**

横切约束(不是模块,是设计红线):

| 老系统的病 | 营造的解法 |
|---|---|
| `company` 字段贯穿全库,行为到处 if 分叉 | 核心只有 organization 概念;公司差异全部沉到插件。核心代码禁止出现任何公司判断 |
| typeness 18 个硬编码业务类型常量(满减/整装…) | 类型可配置;公司专属类型进公司插件 |
| 厂结 / 外销内购 / 集团定材等结算口径 | 结算链路预置钩子(扩展点),专属口径以插件实现 |
| AES 双钥、FL- 工号、内部人事体系 | 通用加密抽象、通用员工编号 |
| constant 表 + ds JSON 双字典源,两份同步发版 | 一套配置化字典,库驱动,改库即生效 |
| functionright 按公司配功能点/查询条件(思想好,实现散) | 吸收思想:功能点权限化、查询条件配置化,统一重设计 |
| 错误码模块分段(110=系统,140=装修…) | **保留**,好设计;每个插件分配独立码段 |
| 非幂等手工菜单/配置 SQL | 全部走 Flyway/Liquibase 版本化迁移,禁止手工 SQL |

## 模块过堂

判定四类:**内核**(平台内核)/ **行业**(行业插件套件)/ **商业**(商业插件候选)/ **删除**。
标 ⏳ 的模块内容未核实,过堂前先读老代码确认。

### 平台内核(自研通用面)

| 老模块 | 内容 | 去向 |
|---|---|---|
| core / common / utils | 拦截器、分页、基础类、工具 | 重写进 `yingzao-core`,只搬思想不搬代码 |
| system | 菜单、系统配置、版本 | 内核:系统管理 |
| right | 权限(RBAC + 数据权限) | 内核:重设计(修掉 oid/company 错配类历史问题) |
| personel | 用户、员工、组织 | 内核:组织架构 + 账号 |
| log | 操作日志、登录日志 | 内核:审计日志 |
| communion | 消息、字典、constant、升级链 | 内核:通知中心 + 配置化字典 |
| imports / exports | Excel 导入导出脚本 | 内核:通用导入导出(保留 exporter 简单框架思想) |
| aliyun | OSS / STS / 图片代理 | 内核:文件存储抽象(可插后端) |
| factory | 授权码 authcode / 开放接口 | 内核:开放 API + SSO(重设计,吸取 buid/timeout 加固教训) |
| secret | 加密 | 内核:安全组件 |
| timer | 定时任务 | 内核:任务调度 |
| approval | 审批流、待办 | 内核:工作流(评估现成引擎 vs 轻量自研,**先 RFC 后动手**) |
| report | 报表平台(metric_* + echarts) | 内核:报表框架;行业报表做行业插件 |
| dingding / wecom / wechat | 钉钉、企微、公众号对接 | 内核:集成适配器(免登 / 消息 / 组织同步) |
| data | 跨域基础数据(定额、材料计划等) | ⏳ 按内容拆:基础模型进内核,业务部分进对应行业插件 |

| 老模块 | 内容 | 去向 |

| construction | 施工:节点、排期、放线、验收、质检、日记 | `addon-construction` |
| sales | 主材销售:销售单、结算 | `addon-sales` |
| inventory | 库存、外辅 | `addon-inventory` |
| material | 材料管理 | `addon-material`(与 sales/inventory 边界待梳理) |

### 删除(方林特性,不进任何层)

- 积分商城 / 会员营销体系(运营特性,若需要以插件形态另起)
- 功勋墙、boss 考勤打卡等内部工具
- OC 厂商 identity 同步等一次性迁移逻辑
- 全部硬编码中文文案(→ i18n 资源文件)
