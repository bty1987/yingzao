## 这是什么

**营造**是一套面向装修行业的开源 ERP:客源、报价、合同、施工、材料、结算——行业全链条业务,一个项目管完。

命名取自宋代李诫《营造法式》——中国第一部建筑设计与施工标准。它的**材分模数制**(构件按标准模数预制、现场拼装)是一千年前的插件化架构;本项目以同样思路构建:**核心只做平台与插件框架,一切业务皆插件,一切公司特性皆插件**。

```text
┌─ 商业插件(闭源)───────────────────────────────────┐
│   电子签 / 外部财务对接 / 工资社保 / 高级报表 / …      │
├─ 行业插件套件(开源,随核心发布)─────────────────────┤
│   客源 / 客户档案 / 报价定额 / 合同 / 施工 / 材料 / 结算 │
├─ 平台内核 yingzao-core(开源)───────────────────────┤
│   插件框架 + RBAC / 组织 / 字典 / 文件 / 通知 / i18n   │
└─ 端 ──────────────────────────────────────────────┘
    Web 后台(Vue3) · uni-app(小程序 + APP) · 企微 / 钉钉 H5 免登
```

## 特性

- **插件化架构**——自研插件框架:扩展点、领域事件、前端槽位注册表、数据扩展约定。公司差异零侵入核心,装哪套插件就是谁家的系统;
- **行业全链条**——客源 → 客户建档 → 报价(定额库)→ 合同 → 施工(节点/排期/验收)→ 主材销售 → 收款结算,一条价值链贯通;
- **一码多端**——Web 管理后台 + uni-app 小程序/APP + 企业微信/钉钉免登 H5,一套账号体系收口;
- **干净的数据模型**——无历史包袱,业务状态机显式化,i18n 从第一行代码开始。
